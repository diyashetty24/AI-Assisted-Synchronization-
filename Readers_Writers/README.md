# Readers-Writers Problem

## Overview

This project implements the Readers-Writers synchronization problem in Python using semaphores and monitors. It also generates HTML simulations based on program execution events.

## Files

- "readers_writers_semaphore.py" – Semaphore-based implementation.
- "readers_writers_monitor.py" – Monitor-based implementation.
- "simlib.py" – Records execution events and generates HTML.
- "template.html" – HTML simulation template.
- "rw_semaphore.html" – Semaphore simulation output.
- "rw_monitor.html" – Monitor simulation output.

## Execution

Run the programs in VS Code:

python readers_writers_semaphore.py
python readers_writers_monitor.py

Open the generated HTML files in a browser to view the simulations.

## Concepts

- Mutual exclusion
- Race conditions
- Reader and writer synchronization
- Starvation and writer preference
