# Overview

This project implements the Readers-Writers and Dining Philosophers problems using semaphores and monitors in Python. It also generates HTML simulations based on program execution events.

 ## Technologies

- Python
- Threading, semaphores, and condition variables
- HTML, CSS, and JavaScript

## Execution

Run the Python programs in VS Code and open the generated HTML files in a browser.
